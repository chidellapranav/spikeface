# LFW board software

The current 64×64 / 53-class design uses `lfw_driver.py`, `export_lfw.py`,
and `run_lfw.py`. Follow [LFW_BOARD_RUN.md](LFW_BOARD_RUN.md) for bundle export
and execution, and [the PL guide](../PL_Design/README.md) for hardware setup.

The previous 32×32 / 40-class driver and deployment instructions are archived
in [../Spike_old/PS/](../Spike_old/PS/README.md). The hardware interfaces differ.
